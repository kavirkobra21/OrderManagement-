# دفترچه سفارش (Order Notebook)

اپلیکیشن Native اندروید (Kotlin + Jetpack Compose + Room) برای مدیریت مشتریان و سفارش‌ها؛ ظاهر برنامه و تصویر خروجی سفارش بر اساس صفحهٔ دفترچه‌ی کاغذی (آبی پاستلی، زرد، سبز، صورتی با حباب‌ها و استیکرها) ساخته شده است.

## امکانات
- ثبت مشتری و سفارش (تاریخ شمسی خودکار، شماره فاکتور خودکار، آیتم‌ها، هزینه کل، بیعانه، باقی‌مانده)
- **تولید تصویر سفارش**: اطلاعات روی قالب دفترچه نوشته می‌شود (متن‌ها در کادرها جا می‌شوند)، ذخیره در گالری، اشتراک‌گذاری، ارسال به تلگرام
- وضعیت سفارش/پرداخت با چک‌باکس، چند عکس برای هر سفارش (رسید، سفارش، محصول نهایی، رضایت مشتری)
- سطل زباله (بازیابی کامل / حذف دائمی / خالی کردن)
- Export/Import بکاپ ZIP با بررسی سلامت و نسخه و تأیید کاربر
- تلگرام از طریق Cloudflare Worker، GitHub Updater، آفلاین‌بودن کامل بخش مشتریان و سفارش‌ها

## ساخت APK (بدون Android Studio)
1. پروژه را در GitHub پوش کنید؛ Workflow در `.github/workflows/build.yml` خودکار اجرا می‌شود.
2. APK را از **Actions → اجرای آخر → Artifacts** بردارید.
3. انتشار نسخه: یک تگ بسازید، مثلاً `git tag v1.0.1 && git push origin v1.0.1`. APK امضاشده به **Releases** اضافه می‌شود و نسخه‌ی برنامه برابر تگ است.

امضا: به‌صورت پیش‌فرض از `app/release.jks` استفاده می‌شود تا نسخه‌های بعدی روی قبلی نصب شوند. برای کلید خصوصی خودتان، Secrets زیر را در GitHub بسازید (`KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) و فایل keystore را مطابق آن قرار دهید. توصیه می‌شود برای انتشار جدی کلید پیش‌فرض را عوض کنید، چون در مخزن موجود است (و اگر عوض شود، نسخه‌های قبلی باید حذف و دوباره نصب شوند).

## تلگرام بدون VPN (Cloudflare Worker)
1. ربات را با `@BotFather` بسازید و در تلگرام **Start** کنید.
2. Chat ID خود را از ربات‌هایی مثل `@userinfobot` بگیرید.
3. در Cloudflare → Workers یک Worker بسازید و محتوای `worker/worker.js` را بگذارید (یا `npx wrangler deploy` داخل پوشه `worker`).
4. **امن‌ترین روش:** در Settings ورکر یک Secret به نام `BOT_TOKEN` بسازید. در برنامه فیلد Bot Token را **خالی** بگذارید؛ توکن هیچ‌وقت روی گوشی نمی‌آید. (اختیاری: Secret `ALLOWED_CHAT_ID` تا Worker فقط به چت شما پیام بدهد.)
5. در برنامه: Settings → آدرس `https://xxxx.workers.dev`، Chat ID را وارد، **بررسی اتصال** و **پیام آزمایشی** را بزنید.

اگر توکن را در برنامه وارد کنید، در `EncryptedSharedPreferences` ذخیره می‌شود (داخل APK نیست). توجه: این روش به محدودیت‌های شبکه و دسترسی به Cloudflare وابسته است و عبور از همهٔ محدودیت‌ها تضمین نمی‌شود.

## بکاپ
Settings → **Export Backup** فایل ZIP می‌سازد (`manifest.json`، `data.json`، پوشه `attachments/`). **Import Backup** ابتدا سلامت و نسخه را بررسی و اطلاعات را نمایش می‌دهد، بعد با تأیید شما همه چیز را جایگزین می‌کند. بکاپ شامل تنظیمات (و توکن‌ها) است؛ آن را در جای امن نگه دارید.

## GitHub Updater
Settings → GitHub Updater: Repository به شکل `owner/repo`؛ برای مخزن خصوصی یک Personal Access Token فقط‌خواندنی (Contents: Read) وارد کنید. «بررسی بروزرسانی» آخرین Release را می‌خواند، تغییرات را نشان می‌دهد و APK را با درصد پیشرفت دانلود و با نصب‌کنندهٔ اندروید نصب می‌کند. داده‌ها هنگام آپدیت پاک نمی‌شوند (applicationId و کلید امضا ثابت است). بار اول اندروید اجازه «نصب از این منبع» را می‌خواهد.

## ساختار
```
app/src/main/java/ir/kavir/ordernotebook/
  data/   Room (Entities, Db), Repo, Prefs (رمزنگاری‌شده), Backup
  net/    Telegram (از طریق Worker), Updater
  ui/     NotebookPage (رندر صفحه دفترچه)، صفحات Compose
worker/   Cloudflare Worker
.github/workflows/build.yml
```

## یادداشت‌ها
- فونت: از فونت فارسی سیستم استفاده می‌شود. برای ظاهر دست‌نویس‌تر، یک فونت (مثلاً در `res/font`) اضافه و در `NotebookPage` به‌جای `Typeface.DEFAULT` استفاده کنید.
- موقعیت دقیق کادرها در `NotebookPage.kt` (مختصات ۱۰۰۰×۱۴۰۰) قابل تنظیم است.
